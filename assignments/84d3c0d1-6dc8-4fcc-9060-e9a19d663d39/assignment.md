# React 状态与事件：计数器和待办事项

## 目标

通过一个包含计数器和待办事项的 Vite + React 小应用，练习函数组件、JSX、props、`useState`、事件处理、条件渲染、列表渲染和不可变状态更新，建立“界面是状态的函数”的 React 心智模型。

完成作业前，请阅读：

- `materials/react-quickstart.md`
- `materials/react-cheatsheet.md`

## 要求

1. 在 `work/<你的用户UUID>/84d3c0d1-6dc8-4fcc-9060-e9a19d663d39/react-basics/` 中创建 Vite + React JavaScript 项目。不要使用 TypeScript。
2. 实现计数器：
   - 显示当前计数，初始值为 `0`。
   - 提供“增加”“减少”和“重置”三个按钮。
   - 计数不得低于 `0`；计数为 `0` 时，“减少”按钮应禁用。
3. 实现待办事项：
   - 可以通过表单添加待办事项，并支持按回车提交。
   - 输入为空或只包含空白字符时不得新增事项。
   - 新增成功后清空输入框。
   - 可以切换每一项的完成状态，也可以删除每一项。
   - 页面显示未完成事项数量；列表为空时显示明确的空状态提示。
4. 至少拆分出 `Counter`、`TodoList` 和 `TodoItem` 组件。通过 props 传递数据或事件回调，不得让子组件直接修改 props。
5. 使用 `useState` 管理交互状态。数组状态必须通过 `map`、`filter` 或展开语法进行不可变更新，不得直接使用 `push`、`splice` 或修改事项对象属性。
6. 每个待办事项必须有稳定且唯一的 ID，并使用该 ID 作为列表 `key`；不得使用数组下标作为 `key`。
7. 页面应具有清晰可读的基础样式，并保证按钮、输入框和待办状态容易辨认。输入框需要可见标签或 `aria-label`。
8. 不引入状态管理库、路由、后端服务或数据持久化。本题不要求保存刷新前的数据。
9. 在项目根目录编写 `README.md`，说明：
   - 安装和运行命令。
   - 组件如何划分，以及状态分别归属哪个组件。
   - 如何实现不可变更新和稳定 `key`。
   - 按下方提交标准逐项记录人工验证结果。

  - 切换完成状态后，未完成数量正确变化；删除事项后列表和数量同步更新。
