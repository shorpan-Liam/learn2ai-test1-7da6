# 作业 2：React 200 字调研报告

## 目标

通过一篇简短的中文调研报告，概括 React 的定位、核心概念和适用价值，并练习从课程资料中提取信息、核对事实和形成自己的判断。

完成作业前，请阅读：

- `materials/react-quickstart.md`
- `materials/react-cheatsheet.md`

## 要求

1. 撰写一篇题为《React 简要调研》的中文报告，正文控制在 180–220 个汉字。标题、标点和文末资料来源不计入正文字数。
2. 正文使用完整段落，不要只罗列项目符号，并包含以下内容：
   - React 是什么，主要用于解决什么问题。
   - 至少两个核心概念，例如组件、JSX、props、state 或单向数据流。
   - React 的一项优势或使用时需要注意的一点。
   - 一句自己的判断，例如 React 适合哪类项目或学习 React 时应重点掌握什么。
3. 报告内容必须基于 `materials/react-quickstart.md` 和 `materials/react-cheatsheet.md`。文末增加“资料来源”一节，列出这两个文件路径。
4. 对照两份资料核对组件、props 和 state 等术语的含义，不得把 React 描述成完整的后端框架，也不得声称它会自动保存应用数据。
5. 将报告保存为 `work/<你的用户UUID>/f1121fae-942a-466a-94ac-7bf677f39cc8/react-report.md`。

## 提交标准

- `react-report.md` 包含报告标题、180–220 个汉字的正文和“资料来源”一节。
- 正文覆盖 React 定位、至少两个核心概念、一项优势或注意点，以及学生自己的判断。
- 术语使用准确，表达通顺，不大段复制课程资料原文。
- 在文件末尾注明正文字数，例如“正文字数：198 字”。
- 成果提交到学生自己的分支，并在应用中确认分享本次学习过程。

## 评分关注点

- 内容是否完整且符合字数要求。
- React 概念是否准确。
- 是否基于指定资料形成了简洁、清楚的个人总结。
