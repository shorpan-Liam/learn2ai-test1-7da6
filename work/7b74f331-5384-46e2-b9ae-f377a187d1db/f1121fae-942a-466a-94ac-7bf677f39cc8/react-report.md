# React 简要调研

React 是用于构建用户界面的 JavaScript 库，主要解决复杂交互页面中界面组织与更新的问题。它把页面拆成职责清晰、可复用的组件，并用 JSX 在 JavaScript 中描述结构。props 是父组件传给子组件的只读输入，state 保存组件的交互状态；状态变化会触发重新渲染，数据通常单向向下传递。React 的优势是声明式开发让界面逻辑更易维护，但对象和数组状态必须不可变更新，也要避免滥用 state。它适合状态较多、需要复用组件的中大型前端项目；学习时应重点掌握组件拆分、状态设计和事件流向。
