## 改进建议

- 当前成果虽然经过自动化交互验证，但验收脚本没有包含在最终成果中，其他人只能依据 README 复述验证过程。后续可以保留一份简洁的测试脚本，并在 `package.json` 中提供 `test` 命令，使验证可以重复执行。
- `vite` 和 `@vitejs/plugin-react` 更适合放在 `devDependencies` 中；依赖声明使用 `latest` 会降低项目初始化时的可重复性，建议明确主版本或具体版本并依靠 lockfile 固定解析结果。
- 对 AI 的使用以“直接完成”为主。下一次提交前，建议用自己的文字补充说明为什么 state 放在当前组件、为什么不能原地修改数组，以及事件如何从子组件传回父组件，以证明自己掌握了实现背后的 React 模型。
